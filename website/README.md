# How to Deploy Your Free Website to GitHub Pages (60 Seconds)

Your website code (`index.html`) and image mockups are already located right in this folder:
📂 `c:\Users\mawakas\Downloads\teepublic assest building\`

Follow these 3 simple steps to make your site live for free:

---

### Step 1: Create a New GitHub Repository
1. Log into your account on [GitHub.com](https://github.com).
2. In the top right corner, click the **`+`** icon → select **`New repository`**.
3. Set the **Repository name**: e.g., `artestheticvibez` (or `midnight-chapter-club`).
4. Keep it **Public**.
5. Do NOT check "Add a README file" (keep it empty).
6. Click **`Create repository`**.

---

### Step 2: Upload Files to the Repository
On the new repository page that appears:
1. Click the link that says: **`uploading an existing file`** (or drag & drop).
2. Select and upload the following files from this folder:
   * `index.html`
   * `store_avatar.png`
   * `pin_1_male_lifestyle.jpg`
   * `pin_2_male_lifestyle.jpg`
   * `pin_3_male_lifestyle.jpg`
3. Click the green **`Commit changes`** button at the bottom.

---

### Step 3: Turn on GitHub Pages
1. In your GitHub repository, click on the **`Settings`** tab (top right gear icon).
2. On the left sidebar menu, click on **`Pages`** (under the "Code and automation" section).
3. Under **Branch**, change **`None`** to **`main`** (or `master`) and keep folder as **`/ (root)`**.
4. Click **`Save`**.

Within 30–60 seconds, GitHub will give you your live URL at the top:
👉 **`https://<your-username>.github.io/<repository-name>/`**

---

### Step 4: Add to Pinterest Profile & Pins
* **Pinterest Profile Website:** Paste your new GitHub Pages link into the **Website** field on your Pinterest profile!
* **Pinterest Pins:** You can now link your pins either directly to this website, or deep-link to the exact shirt:
  * For Pin 1: `https://<your-username>.github.io/<repo>/#fictional-characters`
  * For Pin 2: `https://<your-username>.github.io/<repo>/#midnight-reader`
  * For Pin 3: `https://<your-username>.github.io/<repo>/#old-books-coffee`
